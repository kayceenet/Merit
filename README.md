# MeritPrep — JAMB UTME, WAEC WASSCE & NECO SSCE Prep App

Offline-first Android study & CBT exam simulator built with Jetpack Compose, Material 3, Room, and DataStore across 5 core subjects (Physics, Mathematics, Chemistry, Biology, English Language) and 76 structured Academy lessons with topic-authentic virtual labs.

## Download & Install the Android App (APK)

GitHub repositories display source code by default—the `Code -> Download ZIP` button only downloads source files, not an installable Android app. Use any of the options below to download the installable **`.apk`**:

### 1. Direct Download from GitHub Releases (Recommended)
1. Push this project to your GitHub repository (`main` or `master` branch) and wait ~2–3 minutes for the **Build MeritPrep APK** workflow to finish.
2. Open the **Releases** section on the right side of this GitHub repository page (or use [**Download Latest MeritPrep.apk**](../../releases/latest/download/MeritPrep.apk)).
3. Tap **`MeritPrep.apk`** under **Assets** to download and install it on your Android device (allow *"Install unknown apps"* for your browser/Files app if prompted).

> **Tip:** If you pushed to a branch other than `main`/`master` or want to rebuild manually, open the **Actions** tab → **Build MeritPrep APK** → **Run workflow**.

### 2. Download from GitHub Actions Artifacts
1. Open the **Actions** tab at the top of the repository.
2. Select the latest green **Build MeritPrep APK** run.
3. Scroll to **Artifacts** and download **`MeritPrep-debug-apk`**.

### 3. Export APK Directly Inside Google AI Studio
In Google AI Studio, open the **Settings** menu and choose **Generate APK / AAB** to build and download the installable Android package directly without waiting for GitHub Actions.
